Messages towards the embedder.

A status message to be displayed by the browser chrome.

ShowSimpleDialog(WebViewId, SimpleDialogRequest)

Show the user a simple dialog (alert(), confirm(), or prompt()). Since their messages are controlled by web content, they should be presented to the user in a way that makes them impossible to mistake for browser UI.

Async permission request for screen wake lock. The callback is invoked with the user’s decision, which resolves or rejects the pending promise without blocking the script thread.
