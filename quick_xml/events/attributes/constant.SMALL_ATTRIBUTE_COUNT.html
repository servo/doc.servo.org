const SMALL_ATTRIBUTE_COUNT: usize = 32;
Expand description

Number of attributes a start tag may have before the duplicate-name check switches from a direct linear scan of the previously seen names to a hash pre-filter (see IterState::check_for_duplicates).

Real-world start tags carry only a handful of attributes – the busiest element in our benchmark corpus (tests/documents/players.xml) has 22 – where the scan is faster than hashing and needs no allocation. Larger tags are where the scan became the O(N²) CPU-DoS of #969, so above this count we pay for a hash set to keep the whole tag O(N). The value sits just above the measured linear-vs-hash crossover.
