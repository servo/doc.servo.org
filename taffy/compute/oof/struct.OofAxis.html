Struct OofAxis

struct OofAxis {
    cb_size: f32,
    inset: Line<Option<f32>>,
    margin: Line<Option<f32>>,
    static_position: AxisStaticPosition,
    alignment: OofAlignment,
    safety: AlignmentSafety,
    is_inline: bool,
    reversed: bool,
    is_scroll_axis: bool,
}
Expand description

The inputs to the absolute positioning layout model (https://www.w3.org/TR/css-position-3/#abspos-layout) in a single axis. All coordinates are physical (left-to-right / top-to-bottom) and relative to the start of the containing block’s inset-resolution area.

Fields§

§cb_size: f32

The size of the containing block in this axis

§inset: Line<Option<f32>>

The box’s resolved inset properties (None = auto)

§margin: Line<Option<f32>>

The box’s resolved margins (None = auto)

§static_position: AxisStaticPosition

The box’s static position (relative to the containing block’s inset-resolution area)

§alignment: OofAlignment

The box’s self-alignment in this axis

§safety: AlignmentSafety

The overflow-position modifier of the box’s self-alignment in this axis

§is_inline: bool

Whether this is the inline axis of the containing block

§reversed: bool

Whether the logical start edge of the containing block is the physical end edge of this axis (the inline axis of an RTL containing block)

§is_scroll_axis: bool

Whether the containing block is a scroll container which scrolls in this axis
