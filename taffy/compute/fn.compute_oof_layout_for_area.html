Expand description

Lay out out-of-flow candidates against an explicit positioning area.

Unlike compute_oof_layout, this function does not update the geometry owner’s hoisted children or merge overflow into a LayoutOutput. This is useful when the CSS containing block does not have its own layout node and another node owns the resulting geometry.

geometry_owner supplies the layout tree operations, detailed layout information, and scroll-container state used by the positioning pass. direction and claims describe the actual CSS containing block.
