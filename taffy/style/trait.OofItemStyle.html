Expand description

The styles of an out-of-flow (position: absolute / position: fixed) box that are read by its containing block’s out-of-flow positioning pass

Provided Methods§

Source

fn align_self(&self) -> Option<AlignSelf>

How the box is aligned in the block axis of its inset-modified containing block (align-self). None corresponds to normal/auto.

Source

fn justify_self(&self) -> Option<AlignSelf>

How the box is aligned in the inline axis of its inset-modified containing block (justify-self). None corresponds to normal/auto.

Source

fn is_table(&self) -> bool

Whether the box is a table wrapper box. A normal self-alignment does not stretch tables to fill their inset-modified containing block.

Source

fn grid_row(&self) -> Line<GridPlacement<Self::CustomIdent>>

Defines which row in the grid the box should start and end at, when the box’s containing block is a grid container

fn grid_column(&self) -> Line<GridPlacement<Self::CustomIdent>>
