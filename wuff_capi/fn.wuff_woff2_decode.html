#[unsafe(no_mangle)]
pub unsafe extern "C" fn wuff_woff2_decode(
    data: *const u8,
    length: usize,
    result_length: *mut usize,
) -> *mut u8
Expand description

Decompress a WOFF2 font into a newly-allocated buffer.

On success, returns a pointer to the decompressed font and stores its length in *result_length. The buffer must be freed by passing the returned pointer and length to wuff_woff2_free.

On failure, returns null and stores 0 in *result_length.

§Safety

  • data must either be null (in which case null is returned) or point to length bytes of readable memory.
  • result_length must be a valid pointer to a writable size_t.
