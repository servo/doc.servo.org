    data: *const u8,
    length: usize,
) -> usize
Expand description

Compute the size of the final uncompressed font, or 0 on error.

This reads the totalSfntSize field of the WOFF2 header. It is the C equivalent of the woff2 library’s woff2::ComputeWOFF2FinalSize.

§Safety

data must either be null (in which case 0 is returned) or point to length bytes of readable memory.
