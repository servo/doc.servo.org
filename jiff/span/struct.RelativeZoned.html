fn until(&self, largest: Unit, other: &RelativeZoned<'a>) -> Result<Span, Error>

Returns the result of Zoned::until.

§Errors

Returns an error in the same cases as Zoned::until. That is, when the span for the given largest unit cannot be represented. This can generally only happen when largest is Unit::Nanosecond and the span cannot be represented as a 64-bit integer of nanoseconds.
