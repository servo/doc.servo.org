Expand description

Contains all items needed to build an AST representation of a given Module, as we traverse through syn::ItemMod. We build this up in ModuleBuilder::add

As we traverse through the module, are we inside of #[diplomat::bridge]? If so, then analyze_types is set to true, and types, functions, and traits are all updated according to information parsed.

Otherwise, we traverse through modules until we find a module marked by #[diplomat::bridge]
