pub struct PublicKey {

    pub(crate) e: BoxedUint,
    pub(crate) n_params: BoxedMontyParams,
}
Expand description

Represents the public part of an RSA key.

Fields§

§n: NonZero<BoxedUint>

Modulus: product of prime numbers p and q

§e: BoxedUint

Public exponent: power to which a plaintext message is raised in order to encrypt it.

The recommended value is 0x10001 (65537).

§n_params: BoxedMontyParams

n represented as its Montgomery parameters.

pub const MAX_PUB_EXPONENT: u64

Maximum value of the public exponent e.

Very large public exponents are a potential denial-of-service vector (a.k.a. “RSADoS”) because they increase the amount of work required for e.g. signature verification. See:

https://www.imperialviolet.org/2012/03/17/rsados.html

The particular constant below has been chosen to align with ring where this value was selected based on the history of this particular issue, API compatibility concerns, and benchmark-driven evaluation. See RustCrypto/RSA#155.

If for some reason you have a legitimate reason to use keys with public exponents larger than this value, use the special APIs:

  • PublicKey::new_unchecked
  • [PrivateKey::from_components_with_large_exponent]

pub fn new(n: BoxedUint, e: BoxedUint) -> Result<Self>

Create a new public key from its components.

Accepts modulus sizes from Self::MIN_SIZE to Self::MAX_SIZE, inclusive. Use Self::new_with_size_limits to explicitly allow other sizes.

Source

pub fn new_with_size_limits( n: BoxedUint, e: BoxedUint, size_range_bits: RangeInclusive<usize>, ) -> Result<Self>

Create a new public key with explicit, inclusive modulus size limits in bits.

All other public-key checks still apply. Allowing a smaller minimum can admit insecure keys and is intended for testing or compatibility with legacy systems.

For encoded keys outside the default limits, decode the components with the pkcs1 crate and pass them to this constructor explicitly.

§Errors

Returns Error::InvalidArguments for an empty range, Error::ModulusTooSmall or Error::ModulusTooLarge for a modulus outside the range, or an error if the modulus or public exponent is invalid.

pub fn new_unchecked(n: BoxedUint, e: BoxedUint) -> Self

Create a new public key, bypassing checks around the modulus and public exponent size.

This method is not recommended, and only intended for unusual use cases. Most applications should use PublicKey::new or PublicKey::new_with_size_limits instead.
