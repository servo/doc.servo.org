Expand description

A 256-bit SIMD vector of complex numbers, stored with the real values and imaginary values interleaved. Implemented for __m256, __m256d

This trait implements things specific to 256-types, like splitting a 256 vector into 128 vectors For compiler-placation reasons, all interactions/awareness the scalar type go here
