Expand description

A 128-bit SIMD vector of complex numbers, stored with the real values and imaginary values interleaved. Implemented for __m128, __m128d, but these are all oriented around AVX, so don’t call methods on these from a SSE-only context

This trait implements things specific to 128-types, like merging 2 128 vectors into a 256 vector
