Expand description

Interface to epoll.

Fields§

§epoll_fd: OwnedFd

File descriptor for the epoll instance.

§notifier: Notifier

Notifier used to wake up epoll.

§timer_fd: Option<OwnedFd>

File descriptor for the timerfd that produces timeouts.

Redox does not support timerfd.
