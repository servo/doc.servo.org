Derive a ToTyped implementation for CSS bitflags types.

This mirrors the ToCss bitflags metadata, but with stricter output: Typed OM reification can only produce one TypedValue::Keyword. Mixed values that would serialize to multiple keywords return Err(()).

overlapping_bits needs special handling because some keywords are stored as combinations of lower-level bits. For example, contain: size also contains the inline-size bit internally. The generated code tracks consumed flags so such values still reify to "size" rather than being rejected as multi-keyword values.
