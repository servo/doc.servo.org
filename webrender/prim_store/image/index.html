StretchSizeKey
How to compute the effective stretch size for an image primitive, per axis. FillsPrim resolves to the (snapped) prim-rect extent at frame-build so the value sent to the GPU lands on the snapped pixel grid. Explicit keeps the gecko-specified value verbatim. Per-axis because gecko can specify a background tile that fills the prim on one axis but tiles on the other (e.g. background-repeat: repeat-y with background-size: 116.8px 0.8px).
