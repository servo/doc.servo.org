Fields§

§tail: [u8; 2]

The last bytes of the output (at most two), held back because they hold the ISLAST and ISLASTEMPTY bits that end the stream, which have to go if another stream is appended.

§tail_len: u8§window_size: u8

The first stream’s window size, or 0 before it is known; later streams may not exceed it.

§any_bytes_emitted: bool

Whether any bytes were written; if none are, finish writes an empty stream.

§phase: Phase

Source

fn splice(&mut self, header: &[u8]) -> Result<Option<ByteBuf>, BroCatliResult>

Splices the stream that starts with header onto the output: the output loses its final empty meta-block, the stream loses its window size, and the two are joined bit by bit. The last two bytes of the result become the new tail; the rest is returned, ready to write. Returns Ok(None) if more of the stream is needed to find where it becomes byte aligned.
