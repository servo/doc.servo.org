brotli

Module concat 

Source
Expand description

Joins brotli streams that were compressed to be concatenated (-appendable for the first stream, -catable for the rest) into one stream.

A brotli stream is a sequence of bits, least significant bit first: a window size, then meta-blocks. It ends with an empty meta-block, which is just the two bits ISLAST and ISLASTEMPTY, followed by zero padding to the end of the byte. A catable stream starts with a meta-block whose header leaves the stream byte aligned (an uncompressed or metadata meta-block, or the stream’s final empty one), and it never refers back to data before itself.

So appending stream B to output A only takes changing a few bits where they meet:

  A:            ... | ISLAST ISLASTEMPTY | padding
  B:                                       window size | header | padding | aligned bytes ...
  A then B:     ... | header | padding | aligned bytes ...

A’s ISLAST/ISLASTEMPTY pair always lies in its last two bytes, so BroCatli holds the last two bytes of the output back (the tail) until it knows whether another stream follows, and copies everything else straight through.
