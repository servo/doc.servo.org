Expand description

The FontContext represents the per-thread/thread state necessary for working with fonts. It is the public API used by the layout and paint code. It talks directly to the system font service where required.

A sender that can send messages and receive replies from Paint.

The actual instances of fonts ie a FontTemplate combined with a size and other font properties, along with the font data and a platform font instance.

§resolved_font_groups: RwLock<HashMap<FontGroupCacheKey, Arc<FontGroup>>>

A caching map between the specification of a font in CSS style and resolved FontGroup which contains information about all fonts that can be selected with that style.

§web_fonts: CrossThreadFontStore§webrender_font_keys: RwLock<HashMap<FontIdentifier, FontKey>>

A collection of WebRender FontKeys generated for the web fonts that this FontContext controls.

§webrender_font_instance_keys: RwLock<HashMap<FontParameters, FontInstanceKey>>

A collection of WebRender FontInstanceKeys generated for the web fonts that this FontContext controls.

§font_data: RwLock<HashMap<FontIdentifier, FontData>>

The data for each web font FontIdentifier. This data might be used by more than one FontTemplate as each identifier refers to a URL.

§have_removed_web_fonts: AtomicBool§currently_downloading_fonts: Mutex<HashMap<ServoUrl, Vec<WebFontDownloadState>>>

Maps from a URL to all the @font-face rules that are currently waiting for the load to finish.

§known_font_face_rules: Mutex<KnownFontFaceRules>

The set of @font-face rules that are currently present in the CSS cascade. This is not necessarily equivalent to the rules that actually apply to the page, because rules that are invalid or not yet downloaded are also included.

§font_feature_value_map: RwLock<Option<FontFeatureValueMap>>

A lazily-computed map of feature names from @font-feature-value rules.

§number_of_loading_web_fonts: AtomicUsize

The number of fonts that are currently loading.
