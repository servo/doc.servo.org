Fields§

§script_chan: GenericSender<ScriptThreadMessage>§id: ScriptEventLoopId§background_hang_monitor_sender: Option<GenericSender<BackgroundHangMonitorControlMsg>>

When running in another process, this is an IpcSender to the BackgroundHangMonitor on the other side of the process boundary. When running in the same process, the BackgroundHangMonitor is shared among all EventLoops so this will be None.
