Expand description

A font configured for shaping and font queries.

Uses the font’s own character map and metrics by default. A scale and custom FontFuncs can be set to change the queries used during shaping. Dereferences to the underlying Font for direct font queries.

pub fn default_attributes(&self) -> Attributes

Returns the width, style and weight of the default instance.

For an SFNT font, these come from the OS/2 table, with the post italic angle for an oblique style. If there is no OS/2 table, they come from head. These tables do not vary, so every instance of a variable font returns the same values. To get the attributes at a location, use Attributes::from_variations.

For a Type 1 or standalone CFF font, these come from the Weight name and ItalicAngle.

pub fn is_hint_reliant(&self) -> bool

Returns true if the font needs its TrueType instructions to draw correct contours.

Such fonts are often called “tricky”. They are recognized by family name or by the checksums of the cvt, fpgm and prep tables, and only fonts with glyf outlines qualify. The result is computed once and cached. See is_hint_reliant.

Returns true if the font is a standalone CID-keyed CFF font, whose glyphs are identified by CID.

pub fn max_cid(&self) -> Option<u32>

Returns the largest CID that a CID-keyed font maps to a glyph.

Glyphs in a CID-keyed font can be addressed by CID, so one more than this value is the number of addressable glyph IDs. Returns None if the font is not CID-keyed.

Source

pub fn glyph_by_cid(&self, cid: u32) -> Option<GlyphId>

Returns the glyph for cid in a CID-keyed font.

Where several glyphs have the same CID, the first is returned. Returns None if the font is not CID-keyed or no glyph has cid.

The first call builds a table from each CID to its glyph.
