Expand description

A buffer of text to be shaped, and of the glyphs that shaping produces.

This is the unified buffer type, matching HarfBuzz’s hb_buffer_t. It carries a ContentType describing which of the two states it is currently in.

pub fn set_content_type(&mut self, content_type: Option<ContentType>)

Sets the type of content held by the buffer.

This only relabels the buffer; it never clears it. Shaping sets this to ContentType::Glyphs on its own, so most callers never need it.

Setting it explicitly reinterprets the items already in the buffer, which is occasionally what you want: label a buffer of glyph ids as ContentType::Glyphs to serialize a run that was shaped elsewhere, or label a shaped buffer as ContentType::Unicode to force shape to run over it again.

pub fn set_not_found_variation_selector_glyph(&mut self, glyph: Option<u32>)

Sets the glyph used to replace not-found variation-selector characters.

A variation selector is not present if there is no glyph in the font for the combination with the previous character. If None then the selector is treated as a default ignorable character. If Some(glyph) then the selector is preserved but replaced with glyph with zero advance to allow callers to know about missing glyph combinations. E.g., fall back to another font.

glyph is taken as is and does not have to be present in the font; any u32 value, even above u16::MAX, is accepted.

Block-copies info[src..src + count] to out_info[dst..dst + count]. The caller must have made room in the out buffer already. In the shared-array case the destination never starts past the source (dst <= src), which makes the ascending inline copy overlap-safe.
