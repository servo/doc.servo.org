Module lookup 

Source
Expand description

The lookups of GSUB and GPOS, parsed once and kept with the font tables.

When a lookup is first used, each of its subtables is read into a CachedSubtableKind that holds the parsed table together with everything derived from it: coverage and class tables, digests and glyph lookup caches. Applying a subtable is then one indirect call through CachedSubtable that checks the kind it expects and runs.

The parsed tables borrow the font data, so a lookup is kept in a yoke::Yoke with a reference to the font’s shared tables; see CachedLookupRef.
