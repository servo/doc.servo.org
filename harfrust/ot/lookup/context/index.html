harfrust::ot::lookup

Module context 

Source
Expand description

Contextual and chained contextual subtables, shared by GSUB and GPOS.

A contextual subtable is a chained one without backtrack or lookahead, so both run through the same walks. Only the layout of their rules differs, which RuleLayout records: whether they are chained, and the width of the offsets to them, which the extended formats widen.

Rule values are glyph IDs or classes. The rule walks take their width as a constant, since they read many values per rule: classes are always 16 bits, and only the glyph rules of the extended formats are 24.
