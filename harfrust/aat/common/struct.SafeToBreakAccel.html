Expand description

Per-table acceleration for the drive loops’ safe-to-break computation.

The data for every state-machine subtable in one AAT table is stored in two packed vectors. Each top-level subtable cache carries a compact descriptor for its ranges. This avoids two Vec allocations in every subtable cache while retaining O(classes) + O(states) storage.
