fn error(&self) -> Self::Output

Map a single UTF-8 error to Output.

What constitutes a single error is defined by the WHATWG Encoding Standard.

When Output is char, char::REPLACEMENT_CHARACTER is the appropriate implementation.

The implementation of this method is expected to be declared #[inline(always)].
