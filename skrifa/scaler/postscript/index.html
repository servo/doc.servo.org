PostScript hinting for a ScalerFont.

read-fonts runs the charstrings, and this crate’s PostScript hinter hints them before the font matrix is applied.

Constants§

CACHED_SUBFONTS 🔒
The number of subfonts whose hinting state is kept for a size. A subfont past them is read again for each glyph that needs it, so a font with thousands of subfonts costs no more to configure than one with eight.
