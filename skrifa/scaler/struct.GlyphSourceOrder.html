Struct GlyphSourceOrder 

Source 
pub struct GlyphSourceOrder(u64);
Expand description

An ordered list of glyph sources, most preferred first.

Holds every source, four bits each, in eight bytes. It can be used as a constant and passed by value. A source listed more than once keeps only its first position.

How an order is used depends on the consumer:

  • Outlines use one base source per font. This is the first of Glyf, Cff2, Cff and Type1 that the font contains. If Varc comes before the base source, it applies to the glyphs it covers, and its components are drawn from the base source.
  • Bitmaps use the first of Sbix, Cbdt and Ebdt that the font contains.
  • Glyph extents try each source in the font, in order, until one provides extents for the glyph.

pub const DEFAULT: GlyphSourceOrder

The default order for measuring glyphs: sbix, CBDT, COLR, VARC, glyf, CFF2, CFF, then Type 1 charstrings.

Color bitmaps come first, then color glyphs, then outlines with VARC before its base source. EBDT is not included, so monochrome and grayscale bitmaps are used only when a caller asks for them.
