Source

pub(super) fn program_unhinted_ppem(&self) -> Option<f32>

Returns the size for an unhinted draw when the control value program disabled hinting.

This is the interpreter’s size, because FreeType chooses its scale before it reads the program’s flag. Returns None when hinting is on or when the gasp table disabled it. FreeType checks gasp before choosing a scale, so it draws at the requested size.
