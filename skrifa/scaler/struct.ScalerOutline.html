Struct ScalerOutline

pub struct ScalerOutline<'a> {
    scaler: &'a ScalerFont,
    outline: OutlineGlyph<'a>,
}
Expand description

An outline from a ScalerFont, resolved for drawing.

Holds the outline in its source format. A caller can size its own working memory and then draw without looking up the glyph again.

pub fn required_memory_size(&self) -> usize

Returns the size in bytes of the working memory needed by draw.

Returns zero for the automatic hinter, which manages its own memory.

Source

pub fn draw( &self, memory: DrawMemory<'_>, sink: &mut impl PathSink, ) -> Result<DrawnMetrics, ScaleError>

Draws the outline into sink with the scaler’s size and hinting.

With DrawMemory::Scratch, working memory comes from short lived scratch, which may be allocated on the heap for a large glyph program. Supplied memory must hold at least required_memory_size bytes, or the draw fails with ScaleError::InsufficientMemory.
