Expand description

Draws glyphs from a Font at a size, with optional hinting.

Drawing takes &self, so a scaler is cheap to draw from and safe to share. Working memory comes from the caller or from short lived scratch. reconfigure sets up a scaler for another font, size, or hinting and reuses the existing memory. This lets a cache of scalers reuse its entries.

pub fn unhinted(font: impl Into<ScalerSource>, ppem: Option<f32>) -> Self

Creates a scaler that draws font unhinted.

ppem is the size in pixels per em, or None for font units.

A TrueType font that needs its instructions to draw correct contours is hinted anyway when there is a size. It is hinted with HintOptions::interpreter, which hint_options then returns. Use force_unhinted to draw such a font unhinted.

Source

pub fn force_unhinted(font: impl Into<ScalerSource>, ppem: Option<f32>) -> Self

Creates a scaler that draws font unhinted, even a font that needs its instructions to draw correct contours.

ppem is the size in pixels per em, or None for font units.

Source

pub fn hinted( font: impl Into<ScalerSource>, ppem: f32, hint_options: HintOptions, ) -> Self

Creates a scaler that draws font at ppem pixels per em, hinted as hint_options asks.

Hinting fits an outline to a pixel grid, so it always requires a size.

Source

pub fn reconfigure( &mut self, font: impl Into<ScalerSource>, ppem: f32, hint_options: HintOptions, )

Reconfigures the scaler to draw font at ppem pixels per em, hinted as hint_options asks.

The memory from the previous setup is reused. This lets an entry in a cache of hinted scalers change its font, size, and hinting without creating a new scaler. Setup reruns the font’s programs, so avoid calling this on a hot path. An unhinted scaler is cheap to create, so there is nothing to gain from reconfiguring one; this always leaves the scaler hinted.

pub fn outline_source(&self) -> Option<OutlineSource>

Returns the table that provides the outlines.

This is OutlineSource::Varc if VARC composites are drawn. The composites cover only some glyphs, and the rest come from the underlying_outline_source. Returns None if the font has no outlines from the scaler’s sources.

Source

pub fn underlying_outline_source(&self) -> Option<OutlineSource>

Returns the table that draws the glyphs VARC does not cover and the components of those it does.

This is the same as outline_source unless VARC composites are drawn, and is never OutlineSource::Varc. Returns None if the font has no outlines from the scaler’s sources.

pub fn ppem(&self) -> Option<f32>

Returns the size in pixels per em, or None for font units.

Source

pub fn hinted_ppem(&self) -> Option<f32>

Returns the size glyphs are hinted at, in pixels per em.

This is ppem, except for a TrueType font whose head table asks for whole pixel sizes. The interpreter then hints at the size rounded to a whole pixel, and draws at it too when the font turns hinting off.

Source

pub fn hint_engine(&self) -> Option<HintEngine>

Returns the hinting engine the scaler runs, or None if it does not hint.

A scaler does not hint without hinting options or a size, or where setup failed, which hinting_error reports. A TrueType font can turn its hinting off at some sizes, so the engine can be selected where is_hinted is false.

Source

pub fn hint_options(&self) -> Option<HintOptions>

Returns the hinting configuration, if any.

Source

pub fn is_hinted(&self) -> bool

Returns true if glyphs are hinted at this size.

Returns false if no hinting is configured, if the size is in font units, or if the font has nothing to hint with. Also returns false if the font disables hinting at this size through its control value program or gasp table.

A VARC composite is drawn unhinted unless the automatic hinter is in use, even where this returns true.

Source

pub fn hinting_error(&self) -> Option<&ScaleError>

Returns the error that prevented hinting setup, if any.

Every draw fails with this error until the size or hinting changes.

Source

pub fn raster_policy(&self) -> Option<RasterPolicy>

Returns the smoothing and grid fitting the font requests at this size.

Returns None unless the TrueType interpreter hints the font. With classic ClearType, this is the default policy rather than the font’s.

Source

pub fn metrics(&self) -> ScaledMetrics<'_, ScaleF32>

Returns the metrics describing the font as a whole, in pixels at ppem, or in font units without a size.

These are scaled linearly; hinting does not change them.

Source

pub fn style_metrics(&self) -> ScaledStyleMetrics<'_, ScaleF32>

Returns the font-wide style measurements, in pixels at ppem, or in font units without a size.

These are scaled linearly; hinting does not change them.

Source

pub fn linear_glyph_metrics(&self) -> ScaledGlyphMetrics<'_, 'static, ScaleF32>

Returns the glyph metrics, in pixels at ppem, or in font units without a size.

These are scaled linearly; hinting does not change them. For a hinted glyph’s advance, draw its outline: ScalerOutline::draw returns it in DrawnMetrics::h_advance.

Glyph extents are measured from the sources the scaler draws from, in the same order.
