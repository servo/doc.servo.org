pub fn animate(self, animate: bool) -> Self

Whether to display a loading animation when progress < 1. Note that this will cause the UI to be redrawn. Defaults to false.

If Self::corner_radius and Self::animate are used simultaneously, the animation is not rendered, since it requires a perfect circle to render correctly. However, the UI is still redrawn.

Source

pub fn corner_radius(self, corner_radius: impl Into<CornerRadius>) -> Self

Set the rounding of the progress bar.

If Self::corner_radius and Self::animate are used simultaneously, the animation is not rendered, since it requires a perfect circle to render correctly. However, the UI is still redrawn.
