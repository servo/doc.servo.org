Enum ParseError 

Source 
enum ParseError {
    Xml {
        message: Cow<'static, str>,
        offset: usize,
    },
    Domain(Error),
}
Expand description

A parse failure: either a positioned structural/XML error, or a rejected value (an invalid name or signature) that carries the matching Error variant.
