Expand description

The blend dictionaries of a font as they are read, before they are checked against each other.

Each add fails where FreeType refuses the whole font: a count out of range, a count that disagrees with one already read, or a second design map. A later axis type or position list replaces an earlier one, as in FreeType.

https://gitlab.freedesktop.org/freetype/freetype/-/blob/80a507a6b8e3d2906ad2c8ba69329bd2fb2a85ef/src/type1/t1load.c#L764
