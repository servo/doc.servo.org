fn handle_build_char( &mut self, subr_idx: i32, num_args: usize, ) -> Result<(), Error>

Handles the othersubrs that compute with the BuildCharArray and the blend, 19 to 25 and 27.

Each takes its arguments from the stack and leaves its result there, for the pop that follows. A wrong number of arguments, an index the array cannot hold or a division by zero fails the glyph, as in FreeType.

The array starts out zeroed for each glyph. FreeType keeps one array for the whole font, so a font that reads an element no earlier othersubr in the glyph wrote can differ.

See https://gitlab.freedesktop.org/freetype/freetype/-/blob/80a507a6b8e3d2906ad2c8ba69329bd2fb2a85ef/src/psaux/psintrp.c#L1911
