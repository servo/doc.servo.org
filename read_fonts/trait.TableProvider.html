fn glyf(&self) -> Result<Glyf<'a>, ReadError>

Reads the glyf table only. A font may carry its outlines in GLYF and LOCA instead; selected_glyf_loca chooses between the pairs.

Source

Source

fn loca_extended( &self, is_long: impl Into<Option<bool>>, ) -> Result<Loca<'a>, ReadError>

Source

fn selected_glyf_loca( &self, is_long: impl Into<Option<bool>>, ) -> Result<(Glyf<'a>, Loca<'a>), ReadError>

Selects GLYF/LOCA before glyf/loca, independently of metrics. A present GLYF requires LOCA; it never uses the original loca offsets.

Source

fn gvar(&self) -> Result<Gvar<'a>, ReadError>

Reads the gvar table only. A font may carry its glyph variations in GVAR instead; selected_gvar chooses between them.

Selects GVAR before the original gvar table.
