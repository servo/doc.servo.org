pub struct Font(Repr);
Expand description

A font at one location in its design space.

Cloning is cheap: clones share one instance rather than copying it.

pub fn new(source: impl Into<Source>, index: u32) -> Option<Self>

Creates a font from source, at its default location.

index selects a font within the data:

  • SFNT: the font in a collection (ttc or otc). Data holding a single font accepts only zero.
  • Standalone CFF: the font in the CFF font set.
  • Type 1: ignored, since the data holds one font.
  • TableFunction: ignored, since the function supplies the tables of one font.

Returns None if the source holds no font in a supported format, or none at index.

pub fn default_attributes(&self) -> Attributes

Returns the width, style and weight of the default instance.

For an SFNT font, these come from the OS/2 table, with the post italic angle for an oblique style. If there is no OS/2 table, they come from head. These tables do not vary, so every instance of a variable font returns the same values. To get the attributes at a location, use Attributes::from_variations.

For a Type 1 or standalone CFF font, these come from the Weight name and ItalicAngle.

pub fn is_hint_reliant(&self) -> bool

Returns true if the font needs its TrueType instructions to draw correct contours.

Such fonts are often called “tricky”. They are recognized by family name or by the checksums of the cvt, fpgm and prep tables, and only fonts with glyf outlines qualify. The result is computed once and cached. See is_hint_reliant.

pub fn glyph_by_name(&self, name: &str) -> Option<GlyphId>

Returns the glyph named name.

Names come from the same sources as glyph_names, but a synthesized gidNNN name matches nothing. Where several glyphs share a name, the first is returned.

The first call sorts the font’s names, and later calls search them.

pub fn is_cid_keyed(&self) -> bool

Returns true if the font is a standalone CID-keyed CFF font, whose glyphs are identified by CID.

A CFF table in an SFNT font may be CID-keyed too, but its glyphs are identified by glyph index, as in any SFNT font.

pub fn max_cid(&self) -> Option<u32>

Returns the largest CID that a CID-keyed font maps to a glyph.

Glyphs in a CID-keyed font can be addressed by CID, so one more than this value is the number of addressable glyph IDs. Returns None if the font is not CID-keyed.

pub fn glyph_by_cid(&self, cid: u32) -> Option<GlyphId>

Returns the glyph for cid in a CID-keyed font.

Where several glyphs have the same CID, the first is returned. Returns None if the font is not CID-keyed or no glyph has cid.

The first call builds a table from each CID to its glyph.

pub fn outline_glyphs_with(&self, order: GlyphSourceOrder) -> OutlineGlyphs<'_>

Returns the font’s outlines, using the source order in order.

The first of Glyf, Cff2, Cff and Type1 that the font has becomes the base source for every glyph. If Varc comes before the base source, it applies to the glyphs it covers, and their components are drawn from the base source. Sources that are not outlines are ignored.

pub(crate) fn cff_subfont( &self, source: OutlineSource, index: u16, ) -> Option<Subfont>

Returns subfont index of the charstrings for source, parsed at this instance’s location.

The first CACHED_SUBFONTS subfonts are parsed once and kept, since nearly every glyph in a font shares one of them. A standalone CFF font parses them when the font is read. An SFNT font parses each once per location, when a glyph first needs it. A subfont past them is parsed each time it is asked for, so a font with thousands of subfonts costs no more memory than one with eight.
