Expand description

Measurements of individual glyphs at one location.

Cheap to obtain, so it can be taken per query rather than held.

Measures ink using the sources in order.

Each source in the font is tried in turn until one provides extents for the glyph. GlyphSourceOrder::DEFAULT tries bitmaps, then color, then outlines.

pub(crate) fn with_bitmap_ppem(self, ppem: Option<f32>) -> Self

Measures bitmaps using the strike for ppem.

This selects the smallest strike that is at least ppem, or the largest strike if none is that large. None (the default) or a size that is not positive selects the largest strike. A glyph missing from that strike is measured by the next source in the order, even if another strike contains it. No other metric depends on the size.

pub fn extents(&self, glyph: GlyphId) -> Option<GlyphExtents<f32>>

Returns where glyph’s ink sits, in font units.

An empty glyph has zero extents. None means the glyph is unavailable or its extents could not be read. A bitmap is measured from the font’s largest strike; scaled metrics use the strike for the scale’s size.

See extents_exact for the values before they are narrowed to f32.

pub fn extents_batched<'o, V: 'o>( &self, convert: impl Fn(Option<GlyphExtents<F48Dot16>>) -> V, glyphs: impl Iterator<Item = (GlyphId, &'o mut V)>, )

Writes where each glyph’s ink sits to its slot, in order.

Each measurement passes through convert, so a caller working in another number type writes into that type directly.

The sources are resolved once for the batch, because the available tables depend on the font rather than on the glyph. Each glyph then tries them in order until one provides extents.

Returns the base outline source, where it is the only source in the order that the font has.

This needs no list of sources: the font’s answers about its bitmap, color and composite tables are kept, and the base is chosen as OutlineGlyphs chooses it.
