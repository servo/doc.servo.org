Expand description

Converts a measurement in font units into a caller’s own units.

Written by whatever owns scaling in a text stack: a shaper, or the bridge between one and this crate. Callers that want font units read them from GlyphMetrics, Metrics and StyleMetrics and never implement this.

An implementation chooses the number format, the rounding, and the order of operations for each axis. This crate defines how measurements combine into a metric.

The arithmetic is part of the trait for the same reason: an implementation decides what an overflowing sum does and which way a halved odd number rounds.

Scales a measurement along the y axis.

Separate from scale_x because the two axes need not agree, and because a caller whose y runs down the page says so here.

Source

fn scale_glyph_extents( &self, extents: GlyphExtents<F48Dot16>, ) -> GlyphExtents<Self::Value>

Scales where a glyph’s ink sits.

One call rather than four, so that a scale running the other way up settles in one place what that means for a bearing and a size. The scale also decides whether to round the box’s corners before scaling.

Source

fn scale_rect(&self, bounds: BoundingBox<F48Dot16>) -> BoundingBox<Self::Value>

Scales a region given by its corners.

One call for the same reason as scale_glyph_extents: a scale running the other way up decides here which corner ends up least.

Provided Methods§

fn ppem(&self) -> Option<f32>

Returns the size in pixels per em, if the scale has one.

Embedded bitmaps are measured from the strike selected for this size. None, the default, selects the largest strike.
