Expand description

Access to names in a font.

SFNT names come from the name table. For Type 1 fonts, the available notice, family, weight, full, version, and PostScript names are exposed as name IDs 0, 1, 2, 4, 5, and 6, respectively. A Type 1 Notice may contain either copyright or trademark text; it is exposed as ID 0. The axes of a multiple master font are named by IDs from 256, one per axis, which Axis::name returns. Standalone CFF fonts expose family, weight, full, and PostScript names as IDs 1, 2, 4, and 6, and copyright, version, and notice as IDs 0, 5, and 7.
