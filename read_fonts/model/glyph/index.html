Module glyph

Expand description

Glyph representations: outlines, bitmaps and color.

A font can contain a glyph in several forms. GlyphSource identifies the tables that provide them, and GlyphSourceOrder sets which ones to prefer. Collections and glyphs report a narrower type, outline::OutlineSource or bitmap::BitmapSource, and each converts into a GlyphSource.

The collections outline::OutlineGlyphs and bitmap::BitmapStrikes resolve an order against a font once, and color::ColorGlyphs reads COLR. Glyph metrics use an order to measure ink.
