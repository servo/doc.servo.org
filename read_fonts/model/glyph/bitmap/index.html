Module bitmap 

Source
Expand description

Embedded bitmap glyphs.

A font stores its bitmaps in strikes, one per size. BitmapStrikes reads them from the first of sbix, CBDT and EBDT that a GlyphSourceOrder prefers. It selects a Strike for a size, and a strike returns a BitmapGlyph. The pixels of a BitmapGlyph can be read without knowing how the table stores them.
