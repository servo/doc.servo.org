Color glyphs.

A COLR glyph is painted through a sequence of PaintSink callbacks for transforms, clips, fills and layers. Version 0 glyphs are layers of solid-filled outlines. Version 1 adds gradients, transforms and compositing. ColorGlyph::paint paints both versions in font units at the font’s location.

§Examples

Paint a glyph:

let glyph = font.color_glyphs().get(glyph).expect("a color glyph");
glyph.paint(sink)

Measure a glyph. This uses the clip box if the glyph has one, and the bounds of what it paints otherwise:

if let Some(glyph) = font.color_glyphs().get(glyph) {
    let extents = glyph.extents().expect("a well formed paint graph");
    println!("{extents:?}");
}
