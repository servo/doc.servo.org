pub fn clip_box(&self) -> Option<BoundingBox<f32>>

Returns the clip box for the glyph, in font units at the font’s location, if the table defines one.

Only version 1 tables define clip boxes.

Source

fn clip_box_for_extents(&self) -> Option<BoundingBox<f32>>

Returns the clip box used by extents, with variation deltas rounded to whole units as in HarfBuzz.

Source

pub fn paint(&self, sink: &mut impl PaintSink) -> Result<(), Error>

Paints the glyph into sink, in font units at the font’s location.

A version 1 glyph is clipped to its clip box, if it has one, and its paint graph is traversed from the root. A version 0 glyph fills each of its layers in order.

Source

fn paint_dyn(&self, sink: &mut dyn PaintSink) -> Result<(), Error>

Calls paint through a trait object, so the traversal is compiled once instead of once per sink type.

Source

pub fn extents(&self) -> Result<GlyphExtents<f32>, Error>

Returns the ink bounds of the glyph in font units.

Uses the clip box if the table defines one. Otherwise the glyph is painted and the bounds of its fills are returned. A fill clipped to an outline is measured by the control box of that outline. A glyph that paints nothing has zero extents.
