Expand description

Receives the operations that paint a color glyph.

Each callback is one canvas operation. ColorGlyph::paint calls them with values in font units. A sink that draws at a specific size scales them by size / upem.

fn fill_glyph( &mut self, glyph: GlyphId, brush_transform: Option<Matrix<f32>>, brush: Brush<'_>, )

Clips to the outline of glyph and fills it with brush, with brush_transform applied to the brush alone.

The default implementation uses the other callbacks. Override it if the graphics library can fill a path in one call.

Source

fn paint_cached_color_glyph( &mut self, _glyph: GlyphId, ) -> Result<PaintCachedColorGlyph, Error>

Paints a nested color glyph from the sink’s cache, if it has one.

The glyph is painted unscaled under the current transformation matrix. The default implementation has no cache, so the paint graph of the glyph is traversed.

Source

fn pop_layer(&mut self)

Composites the last layer onto the layer below, using the mode passed to the matching push_layer.

Source

fn pop_layer_with_mode(&mut self, _composite_mode: CompositeMode)

Same as pop_layer, but also receives the composite mode.

Use this for a graphics library that needs the mode when the layer is popped. Only one of the two methods needs an implementation. The default calls pop_layer.
