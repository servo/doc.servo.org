Provides access to the variable composite glyphs in a font.

The length of the longest axis index list in the table.

A list longer than axis_count repeats an axis, and the later value wins.

pub(crate) fn new( varc: Varc<'a>, units_per_em: u16, axis_count: usize, ) -> Result<Self, ReadError>

Creates a new set of composite glyphs from varc.

axis_count is the number of variation axes that components can set. A font without fvar can still have axes in gvar or the CFF2 variation store.

Source

pub(crate) fn covers(&self, glyph: GlyphId) -> bool

Returns true if the table covers glyph.

Source

pub(crate) fn outline(&self, glyph: GlyphId) -> Option<Outline>

Returns the outline for glyph.

Returns None if the table does not cover the glyph. The tree is read only when the glyph is drawn or its memory size is requested.

Source

fn layout_of( &self, outline: &Outline, context: &dyn VarcContext, ) -> Result<Layout, Error>

Returns the memory layout for drawing outline, measuring its tree the first time.

Fails if the glyph data is malformed or the tree passes the recursion or edge limits. Every component counts, whatever its condition, so the answer is the same at every location.

Source

pub(crate) fn required_memory_size( &self, outline: &Outline, context: &dyn VarcContext, ) -> usize

Returns the size in bytes of the memory for drawing outline, or zero if it cannot be drawn.

Source

fn layout(&self, depth: usize, leaf: usize) -> Layout

Returns the memory layout for a composite.

depth is the nesting depth and leaf is the size in bytes of the largest leaf.

Source

fn region_count(&self) -> usize

Returns the number of variation regions, or zero if the table has no variation store.

Source

fn measure( &self, glyph: GlyphId, coverage_index: u32, context: &dyn VarcContext, walk: &mut Walk, ) -> Result<usize, ReadError>

Measures the tree under a composite.

Returns the size in bytes of the largest leaf and records the deepest nesting in walk. Every component is counted regardless of its condition, so the result is valid for any location.

Source

pub(crate) fn draw( &self, outline: &Outline, context: &dyn VarcContext, ppem: Option<f32>, buf: &mut [u8], sink: &mut dyn PathSink, ) -> Result<(), Error>

Draws outline into sink at the location provided by context.

The glyphs at the leaves are drawn by context. ppem is the size of the leaves, or None for font units. It also scales the component offsets. buf must hold at least required_memory_size bytes.
