Outlines from variable composites in VARC.

A variable composite glyph is a tree of components. Each component is a transformed glyph drawn at its own location in the font’s variation space, and may itself be a composite. The leaves are glyphs from the font’s base outline source, glyf or CFF. They are drawn by the OutlineGlyphs that produced the composite.

The working memory a VarcGlyph needs depends on its nesting depth and its largest leaf. The tree is walked to measure them the first time the size is needed, and the result is kept. Drawing splits that memory into typed slices, as the glyf loader does, so a composite needs no memory beyond that buffer.
