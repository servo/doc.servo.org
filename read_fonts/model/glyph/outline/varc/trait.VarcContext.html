Expand description

Provides the data that Outlines::draw needs from outside the table.

This includes the font’s location and the glyphs at the leaves of a composite.

fn coords(&self) -> &[F2Dot14]

Returns the normalized variation coordinates of the font’s location.

A component that resets unspecified axes uses these values.

Source

fn draw_glyph( &self, glyph: GlyphId, coords: &[F2Dot14], ppem: Option<f32>, buf: &mut [u8], sink: &mut dyn PathSink, ) -> Result<(), Error>

Draws glyph into sink at the normalized coordinates coords.

The coords may differ from Self::coords. ppem is the size of the composite, or None for font units. buf is working memory of at least Self::glyph_buffer_size bytes for the glyph.

Source

fn glyph_buffer_size(&self, glyph: GlyphId) -> usize

Returns the size in bytes of the working memory needed to draw glyph.
