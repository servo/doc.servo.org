}
Expand description

A glyph outline from a specific source.

Each variant contains the data needed to draw that source: a glyf plan, a CFF subfont, or a composite tree. To hint an outline, match on the variant and use the source’s own types.

pub fn draw_unscaled( &self, memory: DrawMemory<'_>, sink: &mut dyn UnscaledOutlineSink, ) -> Result<DrawnMetrics, Error>

Sends the outline’s points to sink in font units.

A glyf outline provides its points as stored, with variations applied. Other sources are drawn as a path in font units and converted to points. When a contour closes at its start point, that point is not repeated.

memory works as in draw, with a size given by required_memory_size_unscaled.

A VARC composite has no advance of its own, so the returned metrics have none. Its advance is the one in the font’s metrics tables, from GlyphMetrics::h_advance.

pub fn extents(&self) -> Result<GlyphExtents<f32>, Error>

Returns the extents of the outline in font units.

The extents are computed from the control points, so a curve’s control points are included rather than the curve itself. An empty glyph has zero extents.
