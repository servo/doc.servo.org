Module outline 

Source
Expand description

Scalable glyph outlines.

OutlineGlyphs loads outlines from the source selected by a GlyphSourceOrder. Each OutlineGlyph identifies its source: a glyf::GlyfGlyph, cff::CffGlyph, type1::Type1Glyph or varc::VarcGlyph. Each of these provides access to the source’s own types, which are needed for hinting. These are the glyf loader in tables::glyf::outline and the charstrings in ps.

Outlines are drawn as paths into a PathSink. A Vec of PathElement collects a path, ControlBoundsSink measures it, TransformSink transforms it, SvgSink writes it as SVG path data, and NullSink discards it.
