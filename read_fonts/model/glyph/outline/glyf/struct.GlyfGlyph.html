Struct GlyfGlyph

pub struct GlyfGlyph<'a> {
    context: GlyfContext<'a>,
    plan: OutlinePlan<'a>,
}
Expand description

A TrueType outline from a Font, ready to load.

Contains the OutlinePlan used for both sizing and loading, so the glyph is only walked once no matter how many times it is drawn. The font is the OutlineContext used for loading. To hint, pass a Hinter to OutlinePlan::load with the same context.
