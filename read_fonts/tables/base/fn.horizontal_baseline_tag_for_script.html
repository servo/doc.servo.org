pub fn horizontal_baseline_tag_for_script(script: Tag) -> Tag
Expand description

The baseline horizontal text in a script sits on.

Scripts that hang from a line above take HANGING, ideographic scripts take IDEO_FACE_BOTTOM_OR_LEFT, and everything else, known or not, takes ROMAN.

script is a Unicode script code – Deva, Hani – and not an OpenType script tag. The two are spelled differently: the script Hang is Hangul, while the baseline tag hang is the hanging baseline.

Mirrors HarfBuzz’s hb_ot_layout_get_horizontal_baseline_tag_for_script.
