fn hint(&mut self, zone: &mut GlyphZone<'_, C>) -> Result<(), HintError>

Hints one glyph.

A failure stops the load, which reports it as Error::InvalidOperation. A hinter that wants the detail keeps the HintError itself. The hinter decides whether a failure is fatal: returning Ok carries on with the points as the program left them.

fn round_composite_x_offset(&self) -> bool

Returns whether to round the horizontal offset of a component to the pixel grid.

This applies to composite components with the ROUND_XY_TO_GRID flag. If true, the horizontal offset is rounded along with the vertical one. Otherwise, only the vertical offset is rounded. Defaults to false.
