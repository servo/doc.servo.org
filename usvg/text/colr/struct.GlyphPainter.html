fn outline_glyph(&mut self, glyph_id: GlyphId) -> Option<Rect>

Outlines a glyph into path_buf at the current variation location (an empty path on failure), records the current transform as the outline transform and returns the outline’s conservative bounding box in the glyph’s local coordinate space.
