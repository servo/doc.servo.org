Expand description

Parses an OsStr into a &str when &[u8] isn’t easily available.

The main difference between this and OsStr::to_str is that this will be a zero-cost conversion on Unix platforms to &[u8]. On Windows, this will do UTF-8 validation and return an error if it’s invalid UTF-8.
