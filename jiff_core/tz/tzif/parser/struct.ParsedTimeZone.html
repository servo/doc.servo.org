fn find_or_create_designation(&mut self, needle: &str) -> Option<u8>

Looks for a designation matching needle and returns its offset.

If one is not found, then a new designation is added and its new offset is returned.

If the offset of the designation exceeds u8::MAX, then this returns None. This is not possible for designations in a RFC 9636 TZif file, since their offsets are always a single byte big. However, it is theoretically possible for this to return None on conforming data when fattening is enabled. In which case, it’s possible for new local time types to be added beyond the maximum. But this would require its POSIX time zone to use a local time type not found in the file already.
