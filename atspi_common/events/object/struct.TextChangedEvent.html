Struct TextChangedEvent

pub struct TextChangedEvent {
    pub item: ObjectRefOwned,
    pub operation: Operation,
    pub start_pos: i32,
    pub length: i32,
    pub text: String,
}
Expand description

Text has changed within the UI element item.

Fields§

§item: ObjectRefOwned

The crate::ObjectRef which the event applies to.

§operation: Operation

The crate::Operation being performed.

§start_pos: i32

starting index of the insertion/deletion

NOTE: This gives the Unicode index (not the byte index). I.e., it groups unicode sequences into one character. Always use the appropriate insertion methods to deal with this, i.e., do not use String::insert_str.

§length: i32

length of the insertion/deletion

NOTE: This gives the unicode length (not the byte length).

§text: String

the text being inserted/deleted
