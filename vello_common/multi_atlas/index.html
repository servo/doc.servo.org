Module multi_atlas 

Source
Expand description

Multi-atlas management for texture atlases.

This module provides support for managing multiple texture atlases, allowing for handling of large numbers of images.

The allocator backend is guillotiere’s tree-based guillotine algorithm, providing O(1) neighbor lookup during deallocation and automatic free-rect coalescing.
