§metadata: ImageMetadata§format: PixelFormat§id: Option<ImageKey>§cors_status: CorsStatus§bytes: Arc<Vec<u8>>§frames: Vec<ImageFrame>§is_opaque: bool

Whether or not all of the frames of this image are opaque.

§loop_count: Option<Repeat>

The loop count for this image’s animation. For animated images, this has a default value of Repeat::Infinite (if no loop count is specified in the image). For images that do not animate, this will be None.
