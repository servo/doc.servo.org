pub(crate) fn new(main_thread_sender: Option<ScriptEventLoopSender>) -> Runtime

Create a new runtime, optionally with the given [SendableTaskSource] for networking.

§Safety

If panicking does not abort the program, any threads with child runtimes will continue executing after the thread with the parent runtime panics, but they will be in an invalid and undefined state.

This, like many calls to SpiderMoney API, is unsafe.

pub(crate) unsafe fn new_with_parent( parent: Option<ParentRuntime>, script_event_loop_sender: Option<ScriptEventLoopSender>, ) -> Runtime

Create a new runtime, optionally with the given ParentRuntime and [SendableTaskSource] for networking.

§Safety

If panicking does not abort the program, any threads with child runtimes will continue executing after the thread with the parent runtime panics, but they will be in an invalid and undefined state.

The parent pointer in the ParentRuntime argument must point to a valid object in memory.

This, like many calls to the SpiderMoney API, is unsafe.
