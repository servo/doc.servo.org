UnrootedFollowingFlatTreeNodesTraversal 🔒
A traversal of a [Document]’s flat tree. This is both a pre-order and post-order unrooted traversal. This means that an item is returned both when encountering a node for the first time and when leaving a node. In addition, no garbage collection can happen while iterating, allowing returning unrooted values for performance reasons.
