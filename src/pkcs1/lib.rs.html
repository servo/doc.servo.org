18//! ## Usage
19//!
20//! ### Borrowed DER decoding
21//!
22//! [`RsaPrivateKeyRef`] and [`RsaPublicKeyRef`] borrow their integer data from the input.
23//! Import [`der::Decode`] to use `from_der`:
24//!
25//! ```rust
26//! use pkcs1::{RsaPrivateKeyRef, der::Decode};
27//!
28//! # let der = include_bytes!(concat!(env!("CARGO_MANIFEST_DIR"), "/tests/examples/rsa2048-priv.der"));
29//! let key = RsaPrivateKeyRef::from_der(der)?;
30//! # Ok::<(), pkcs1::Error>(())
31//! ```
32//!
33//! Here, `der` is a byte slice containing a PKCS#1 DER-encoded private key.
34//! `RsaPrivateKeyRef::try_from(der)` also decodes DER when `der` has type `&[u8]`.
35//! Both methods are available without enabling any features.
36//!
37//! ### Owned DER decoding and encoding
38//!
39//! Enable the `alloc` feature to use [`RsaPrivateKeyOwned`] and [`RsaPublicKeyOwned`].
40//! These types own their integer data and implement [`DecodeRsaPrivateKey`] and
41//! [`DecodeRsaPublicKey`], respectively:
42//!
43//! ```rust
44//! # #[cfg(feature = "alloc")]
45//! # {
46//! use pkcs1::{DecodeRsaPrivateKey, EncodeRsaPrivateKey, RsaPrivateKeyOwned};
47//!
48//! # let der = include_bytes!(concat!(env!("CARGO_MANIFEST_DIR"), "/tests/examples/rsa2048-priv.der"));
49//! let key = RsaPrivateKeyOwned::from_pkcs1_der(der)?;
50//! let document = key.to_pkcs1_der()?;
51//! assert_eq!(document.as_bytes(), der);
52//! # }
53//! # Ok::<(), pkcs1::Error>(())
54//! ```
55//!
56//! [`EncodeRsaPrivateKey`] and [`EncodeRsaPublicKey`] support both borrowed and owned keys.
57//! The decoding traits require owned results; use [`der::Decode`] for the borrowed types as shown
58//! above. RSA implementations can also implement these traits for their own key types.
59//!
60//! ### PEM decoding and encoding
61//!
62//! Enable the `pem` feature (which also enables `alloc`) to use `from_pkcs1_pem` and
63//! `to_pkcs1_pem` with the PEM labels shown above:
64//!
65//! ```rust
66//! # #[cfg(feature = "pem")]
67//! # {
68//! use pkcs1::{DecodeRsaPrivateKey, EncodeRsaPrivateKey, LineEnding, RsaPrivateKeyOwned};
69//!
70//! # let pem = include_str!(concat!(env!("CARGO_MANIFEST_DIR"), "/tests/examples/rsa2048-priv.pem"));
71//! let key = RsaPrivateKeyOwned::from_pkcs1_pem(pem)?;
72//! let encoded = key.to_pkcs1_pem(LineEnding::LF)?;
73//! assert_eq!(encoded.as_str(), pem);
74//! # }
75//! # Ok::<(), pkcs1::Error>(())
76//! ```
77//!
78//! Here, `pem` is a string containing a PEM-encoded RSA private key.
79//!
80//! For public  keys, use `RsaPublicKeyOwned` with `DecodeRsaPublicKey` and `EncodeRsaPublicKey`
81//! (the method names are the same).
