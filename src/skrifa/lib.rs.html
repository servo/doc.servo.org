1//! Drawing glyphs from fonts at a size, with hinting.
2//!
3//! A [`Font`] is a font at a location in its variation space. A
4//! [`ScalerFont`] draws the font's glyph outlines at a size in pixels per em,
5//! hinted or not.
6//!
7//! ```
8//! use skrifa::{
9//!     font::{glyph::outline::SvgSink, Font},
10//!     DrawMemory, HintOptions, RasterTarget, ScalerFont,
11//! };
12//!
13//! # fn wrapper(data: Vec<u8>) -> Result<(), skrifa::ScaleError> {
14//! // Load the first font in the file and create a bold instance.
15//! let font = Font::new(data, 0).unwrap();
16//! let bold = font.instance_builder().variations([("wght", 700.0)]).build();
17//!
18//! // Find the glyph ID for the character 'A'.
19//! let glyph_id = bold.charmap().map_unicode('A').unwrap_or_default();
20//!
21//! // Configure a scaler font for hinted drawing at 16 pixels per em, using
22//! // the interpreter with a horizontal subpixel target.
23//! let options = HintOptions::interpreter().with_target(RasterTarget::Lcd);
24//! let scaler = ScalerFont::hinted(bold, 16.0, options);
25//!
26//! if let Some(outline) = scaler.outline(glyph_id) {
27//!     let mut path = SvgSink::new();
28//!     // Draw into the path and store the resulting metrics.
29//!     let metrics = outline.draw(DrawMemory::Scratch, &mut path)?;
30//!     println!("{path} advances by {:?}", metrics.h_advance);
31//! }
32//! # Ok(())
33//! # }
34//! ```
35//!
36//! # Drawing
37//!
38//! [`ScalerFont::outline`] returns a glyph's outline as a [`ScalerOutline`],
39//! which draws into any [`PathSink`]. Drawing needs working memory. By
40//! default it uses short-lived scratch memory, and a caller drawing many
41//! glyphs can supply a reusable buffer instead.
42//!
43//! A scaler draws from the first outline table the font contains, in
44//! [`GlyphSourceOrder::DEFAULT`]: `VARC` composites over `glyf`, `CFF2`,
45//! `CFF` or Type 1 charstrings. To choose other tables, pass a
46//! [`ScalerSource`] in place of the font. The scaler reports the tables it
47//! draws from.
48//!
49//! A scaler with no size draws in font units.
50//!
51//! # Hinting
52//!
53//! Hinting fits an outline to the pixel grid at the scaler's size.
54//! [`HintOptions`] configures it:
55//!
56//! - **Engine.** Run the font's own hints, either TrueType instructions or
57//!   PostScript hints; run the automatic hinter, which derives hints from
58//!   the outline; or pick based on the font, using its own hints where they
59//!   are worth running. A TrueType font that needs its instructions to draw
60//!   correct contours always runs them.
61//! - **Target.** Monochrome, grayscale, light grayscale, or horizontal or
62//!   vertical subpixel rendering. Each target hints to suit the way its
63//!   pixels are drawn.
64//! - **Linear metrics.** Hint only vertically, keeping the unhinted
65//!   horizontal shape and spacing.
66//! - **ClearType compatibility.** Choose between the current ClearType
67//!   behavior of the TrueType interpreter, which follows the font's `gasp`
68//!   table, and the classic behavior, which grid fits every glyph.
69//! - **Strictness.** Fail a draw when a glyph's instructions fail, instead of
70//!   keeping the outline as they left it.
71//!
72//! The scaler reports the engine that runs, and the rasterizer settings the
73//! font requests at the size: whether to smooth along both axes, and the
74//! dropout control a glyph asks of a monochrome rasterizer.
75//!
76//! # Metrics
77//!
78//! A scaler returns the font's line metrics and heights, its style metrics
79//! such as the underline and italic angle, and the advance and bounds of each
80//! glyph, all scaled linearly to its size. Hinting can change a glyph's
81//! advance, so hinted glyph metrics come from drawing the outline.
82//!
83//! # The font model
84//!
85//! The [`font`] module holds everything else about a font: its character
86//! map, names, variation axes and instances, and color and bitmap glyphs.
87//!
88//! # Need shaping?
89//!
90//! [HarfRust](https://docs.rs/harfrust) turns text into positioned glyphs.
91//! It reads fonts through the same font model, so a [`Font`] can be shaped
92//! with HarfRust and drawn with a [`ScalerFont`].
