Trait ZeroizeOnDrop 

Source 
pub trait ZeroizeOnDrop { }
Expand description

Marker trait signifying that this type will Zeroize::zeroize itself on Drop.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
