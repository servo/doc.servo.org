Struct RootedTraceableBox

pub struct RootedTraceableBox<T>(RootedTraceableBox<T>)
where
    T: Traceable + 'static;
Expand description

Roots any JSTraceable thing, at the cost of wrapping it in a Box. Unlike the rooted! macro, the resulting RootedTraceableBox can be safely moved. RootedTraceableBox is slower to create and drop than roots created by rooted!, due to the extra allocations involved.

If you have a valid DomObject, use DomRoot. If you have GC things like *mut JSObject or JSVal, or anything implementing Rootable, use rooted!. If you have an arbitrary number of DomObjects to root, use rooted_vec!. If your needs are not covered by the previous options, use RootedTraceableBox.
